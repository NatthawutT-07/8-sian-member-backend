# อัปเดต backend: ชำระ POS ด้วยเงินสดร่วมกับเงินโอน

เพิ่มวิธีชำระ `MIXED` และ `PosSale.transferSatang` เพื่อเก็บส่วนที่โอน สำหรับบิลผสม `receivedSatang` เป็นเงินสดที่รับรวมกับเงินโอน และ `changeSatang` เป็นยอดรับรวมลบยอดบิล รายงานรายวัน/ปิดกะแยกเงินสดสุทธิหลังทอนและเงินโอน บิลเงินสด/โอนเดิมยังทำงานตามเดิม

ต้องลง migration `202611180001_pos_mixed_payment` ก่อนเริ่ม backend รุ่นนี้ แล้วจึงอัปเดตแอป POS ไม่ต้องเพิ่มตัวแปร `.env` ชุดนี้ไม่เปลี่ยนข้อมูลบิลเก่า

บน server ให้สำรองฐานข้อมูลก่อน (เปลี่ยนชื่อฐานข้อมูล/path/PM2 หาก deployment ของร้านต่างจากนี้):

```bash
mkdir -p ~/backups && chmod 700 ~/backups &&
sudo -u postgres pg_dump -Fc sian_member > ~/backups/sian_member_$(date +%Y%m%d_%H%M%S).dump
```

ตรวจว่า backup สำเร็จ จากนั้นตรวจงานค้างก่อน pull หากมีงานค้างให้เก็บงานก่อน ห้าม reset ทับ:

```bash
cd ~/8-sian-member-backend
git status --short
git pull --ff-only origin main
git log -1 --oneline
```

ช่วงบำรุงรักษา:

```bash
pm2 stop 8sian-backend &&
npm ci &&
npm run generate &&
npm run migrate &&
pm2 restart 8sian-backend --update-env
```

ถ้าขั้นใดผิดพลาดให้หยุดและแก้ก่อนทำต่อ ห้ามใช้ `migrate reset` ตรวจผล:

```bash
npx prisma migrate status
curl --fail-with-body http://127.0.0.1:3001/api/health
curl --fail-with-body https://api.8sianracha.com/api/health
pm2 logs 8sian-backend --lines 50 --nostream
pm2 status
pm2 save
```

Health ต้องตอบ `{"status":"ok"}` และ migration ไม่มีรายการค้าง ทดสอบบิล 1,000 บาท โอน 600 รับสด 500: ทอน 100, รายงานเงินสดสุทธิ 400, เงินโอน 600
